# Ahmed Ali — Portfolio OS v4

## Install
Replace these files in your Vite React project's `src` folder:
- `App.jsx`
- `App.css`
- `NetworkBg.jsx`
- `index.css`

## Public assets
Place these files in the project's `public` folder:
- `portrait.png` — your cinematic portrait (referenced by the hero)
- `Ahmed-Ali-CV.pdf` — your real CV PDF (referenced in the CV section)

## Run
```bash
npm install
npm run dev
```
